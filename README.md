# linux-admin

Small Linux administration shell scripts for day-to-day operational checks.

## Script

- `scripts/linux_admin.sh`

## Usage

```bash
chmod +x scripts/linux_admin.sh
./scripts/linux_admin.sh help
./scripts/linux_admin.sh system-info
./scripts/linux_admin.sh disk-usage
./scripts/linux_admin.sh memory-usage
./scripts/linux_admin.sh top-processes
```
